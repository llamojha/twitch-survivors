# Codex collaboration records

This directory contains project notes, not credentials or Codex runtime configuration.

- [Current handoff](STATUS.md): where work stands and what to do next.
- [Project instructions](../AGENTS.md): rules for maintaining these records.
- [Implementation TODO](../docs/implementation-plan.md): authoritative ordered task list.
- [Product specification](../docs/product-spec.md): requirements and decisions.
- [Work log](../docs/hackathon.md): chronological changes and verification.
- [Session snapshots](../.memory/sessions/): durable checkpoints saved on request.

Read the handoff at session start and update it after meaningful work. Keep historical detail in the work log and snapshots rather than duplicating it here.
