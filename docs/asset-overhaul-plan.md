# Twitch Survivors release asset plan

**Goal:** Replace all Pokémon identity and all uncleared character/world art in the pinned JPTER78 fork with a coherent original or explicitly licensed pixel-fantasy presentation while preserving procedural generation, collisions, combat, progression, and audience systems.

**Timing:** This remains the final implementation milestone. Inherited assets are development placeholders only.

**Code baseline:** `JPTER78/pokesurvivor@b29708900da26b34e70d2dc07ad1659a719f4a78`.

## Release boundary

| Upstream content | Release decision |
| --- | --- |
| `assets/pokemon/**` | Replace all runtime use, then remove. SpriteCollab art is CC BY-NC and Pokémon characters remain protected identity. |
| World art generated by `js/world/tiles.js` | Redesign its palettes, tile pixels, objects, and biome presentation while preserving chunk and collision semantics. |
| Pokémon data in `js/data/pokedex.js`, `starters.js`, `enemies.js` | Keep stable internal IDs temporarily where useful, but map all reachable display names, actors, portraits, types, and descriptions to fantasy content. |
| Moves and VFX in `js/data/moves.js`, `js/entities/vfx.js`, `js/entities/fx.js` | Keep generic mechanics. Rename or redraw franchise-specific presentation; record provenance for every shipped external asset. |
| Pixelify Sans | May remain under OFL with its notice. |
| Upstream code | Keep the MIT notice for the pinned revision and describe material modifications. |
| Post-`b297089` code or assets | Do not copy without separate permission. Visual observation may inform quality goals, not implementation copying. |

## Art contract

- Readable pixel fantasy: adventurer/hero, knights or simple companions, magic, monsters, and bosses.
- Preserve the upstream's ground-plane coordinates, foot anchors, eight-direction animation order, shadows, integer scaling, and front/back draw ordering.
- Preserve 16×16 world chunk behavior and the current collision/object semantics even when tile pixels change.
- Use a small reusable archetype set for the MVP instead of recreating hundreds of inherited species one-for-one.
- Record creator, source, license, modifications, and covered files in `docs/asset-provenance.md` when each asset lands.
- Approve one in-game vertical slice before producing the full set.

## Risks and rollback

- **Sprite alignment:** The upstream animation system depends on per-animation dimensions and ground anchors. Validate metadata before bulk actor production.
- **World regression:** Procedural tile pixels and collision semantics are coupled. Compare deterministic seeds and keep terrain conversion separate from actor conversion.
- **License confusion:** The pinned code is MIT; Pokémon/SpriteCollab assets are not. Keep the distinction visible in provenance and release checks.
- **Save compatibility:** Change presentation before internal keys. Any later key migration needs explicit versioning and non-destructive tests.
- **Performance:** Large actor sheets and labels can erase the upstream's performance advantage. Repeat sustained measurements with final art.
- **Rollback:** Land inventory, vertical slice, terrain, actors, VFX/branding, and purge as separate reviewable changes so any visual slice can be reverted without removing Twitch gameplay.
