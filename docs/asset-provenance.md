## Project-created presentation

The following presentation is generated by Twitch Survivors code and does not add a separate external art dependency:

- `js/data/presentation.js` maps stable gameplay IDs to fantasy names and Kenney actor cells. It also contains a code-drawn fallback for actors while the image is unavailable.
- `js/data/roster.js` defines the compact fantasy roster and keeps numeric IDs solely as internal gameplay/save contracts.
- `js/world/tiles.js` draws terrain procedurally in Canvas from project-defined pixel palettes. The first three run biomes are Verdant Ruins, Moonlit Grotto, and Ember Keep.

Project-created code remains covered by the repository's code license and notices. This section does not approve any other inherited image, sound, icon, copy, or data file.

## Explicitly excluded from release approval

The following inherited content is not approved for the Twitch Survivors distributable release:

- `assets/pokemon/**` and SpriteCollab artwork.
- Pokémon species names, portraits, type presentation, Pokédex wording, trademarked characters, and related identity.
- PokéAPI-derived identity data when exposed to players.
- Any post-`b29708900da26b34e70d2dc07ad1659a719f4a78` upstream code or asset that lacks separate permission.
- Any asset or remote URL absent from this provenance record and the production allowlist.

These files may still exist as development leftovers while the final purge is in progress. Their presence means the package is not release-approved, even if runtime code no longer loads them.

## Release procedure

Before release:

1. Inventory every runtime-reachable image, font, icon, sound, generated visual, visible identity term, and remote asset URL.
2. Add each retained external asset to the approved table with its creator, primary source, license, repository paths, and modifications.
3. Remove excluded and unused inherited assets after references reach zero.
4. Run the source and generated-output asset audit.
5. Verify the production build in a browser and update this document if the shipped set differs.
